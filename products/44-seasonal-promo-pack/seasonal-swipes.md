# Year-Round Promo Calendar + Seasonal Swipes

Replace `[PRODUCT]`, `[OFFER]`, `[BONUS]`, `[DEADLINE]`, `[LINK]`. Only use real urgency.

## The annual promo calendar

| Month | Key angles |
|-------|-----------|
| January | New Year / "new you" / goal-setting / fresh start |
| February | Valentine's, "show yourself some love" (self-investment) |
| March | Spring cleaning / spring into action / Q1 review |
| April | Tax season (finance niches), "spring refresh" |
| May | Mid-year momentum, "halfway to your goals" |
| June | Summer kickoff, "summer project" |
| July | Mid-year review, summer flash sale |
| August | Back-to-school / "back to business" / learn-a-skill |
| September | Q4 prep, "finish the year strong" |
| October | Pre-holiday warm-up, "get ready for Q4" |
| November | **Black Friday / Cyber Monday** (biggest of the year) |
| December | Year-end, "new year prep", holiday, "last chance 2026" |

Plus evergreen manufactured events anytime: anniversary sale, flash bonus weekend,
milestone celebration, "bonus expiring" pushes.
