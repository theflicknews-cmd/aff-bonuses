## Why YouTube wins for affiliates

- **Evergreen:** a review ranks and earns for years.
- **Buyer intent:** "`[product]` review" searchers are ready to buy.
- **Trust:** video builds more trust than text — higher conversions.
- **Two search engines:** YouTube + Google both surface your videos.

## The video types that earn commissions

1. **Reviews** — "`[Product]` Review 2026" (highest intent).
2. **Tutorials** — "How to `[result]` with `[product]`."
3. **Comparisons** — "`[A]` vs `[B]`."
4. **Listicles** — "`[#]` Best `[tools]` for `[goal]`."
5. **Case studies** — "How I `[result]` using `[product]`."

Use Product 7's scripts to write each one.

## Algorithm basics (what actually moves views)

- **Click-through rate (CTR):** title + thumbnail. Aim for curiosity + clarity.
- **Watch time / retention:** hook in 15 seconds, no fluff, deliver fast.
- **Session time:** end screens + playlists keep people on YouTube (it rewards you).
- **Consistency:** a predictable upload cadence trains the algorithm and audience.

## Channel setup essentials

- [ ] Clear channel name + niche-focused banner
- [ ] "About" section with keywords + your link
- [ ] A link hub in the description (-> bonus/review page)
- [ ] Playlists organized by topic
- [ ] Channel trailer for new visitors

## Monetizing every video

1. Affiliate + bonus links in the description (top, above the fold).
2. Pinned comment with the link + a one-line CTA.
3. Say the CTA out loud ("link in the description").
4. End screen pointing to your best review or playlist.
5. Always include an affiliate disclosure.
