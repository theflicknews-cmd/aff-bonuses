# Per-Video SEO Checklist + Content Plan

Run this checklist on every upload so each video has the best shot at ranking.

## Before filming
- [ ] Pick a buyer-intent keyword ("`[product]` review", "best `[category]`")
- [ ] Confirm people search it (autocomplete suggestions, related videos exist)
- [ ] Write a script with a 15-second hook (Product 7)
- [ ] Plan the one CTA (your bonus/review page)

## Title (the #1 CTR lever)
- [ ] Include the exact keyword near the front
- [ ] Add a curiosity or benefit element ("...Is It Worth It?", "...Honest Review")
- [ ] Keep it under ~60 characters so it doesn't truncate
- [ ] Include the year for review/comparison videos (2026)

## Thumbnail
- [ ] Big, readable text (3-4 words max)
- [ ] High contrast, expressive face or clear product shot
- [ ] Readable on mobile at small size
- [ ] Consistent style so your channel is recognizable

## Description
- [ ] First 2 lines: keyword + hook (shows above "more")
- [ ] Affiliate + bonus link near the top
- [ ] Timestamps/chapters
- [ ] 100-200 words with related keywords
- [ ] Affiliate disclosure

## Tags & metadata
- [ ] Primary keyword + 5-10 related tags
- [ ] Add to a relevant playlist
- [ ] Set an end screen (best video / playlist / subscribe)
- [ ] Add cards linking to related reviews

## After publishing
- [ ] Pin a comment with the link + CTA
- [ ] Reply to early comments (boosts engagement)
- [ ] Share to your other channels + email list
- [ ] Check retention after 48h; note where people drop off
