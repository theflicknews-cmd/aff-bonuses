# Product 2 — High-Converting Bonus Page Kit

**Niche:** Affiliate Marketing
**Format:** Editable HTML template + fill-in-the-blank swipe copy
**Perceived value:** $67

Most affiliates lose the sale because their bonus page is ugly, slow, or unclear.
This kit gives buyers a **clean, mobile-friendly, copy-paste bonus page** they can
launch in 10 minutes — plus the proven copy structure to fill it in.

## What's inside

- [`bonus-page.html`](bonus-page.html) — a self-contained, responsive bonus page
  (no frameworks, no build step — just edit the text and links).
- [`swipe-copy.md`](swipe-copy.md) — fill-in-the-blank copy blocks (headline,
  bullets, bonus descriptions, urgency, FAQ, CTA).

## Quick start (for the affiliate)

1. Open `bonus-page.html` in any text editor.
2. Find/replace these placeholders:
   - `{{PRODUCT_NAME}}` — the offer you're promoting
   - `{{AFFILIATE_LINK}}` — your hoplink / affiliate URL
   - `{{YOUR_NAME}}` and `{{YOUR_BRAND}}`
   - `{{DEADLINE}}` — bonus expiry (optional)
3. Edit the 5 bonus slots (`{{BONUS_1_TITLE}}` … `{{BONUS_5_TITLE}}`).
4. Save and upload to any host (your site, Netlify, GitHub Pages, etc.).
5. Drive traffic. The big button goes straight to your affiliate link.

## Why it converts

- **Above-the-fold CTA** — buyers see the action immediately.
- **Bonus stack with values** — anchors a total $ value far above the price.
- **"How to claim" steps** — removes confusion (the #1 refund/chargeback cause).
- **Urgency block** — optional deadline to drive same-session action.
- **Mobile-first** — most affiliate traffic is mobile.
