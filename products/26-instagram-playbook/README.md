# Product 26 — Instagram Affiliate Marketing Playbook

**Niche:** Social Media
**Format:** Growth + monetization strategy + content templates
**Perceived value:** $57

Instagram blends discovery (Reels, Explore) with deep trust (Stories, DMs) — a
perfect combo for affiliate sales. This playbook shows buyers how to grow an
Instagram audience and turn it into commissions.

## What's inside

- This guide — the IG growth system + how each feature sells
- [`content-templates.md`](content-templates.md) — post, Story, and bio templates

## How each Instagram surface sells

| Surface | Job | Affiliate use |
|---------|-----|---------------|
| Reels | Reach / discovery | Hook new people (Product 15 hooks) |
| Feed posts/carousels | Authority / saves | Teach, build trust |
| Stories | Daily trust + selling | Polls, behind-the-scenes, link stickers |
| Highlights | Evergreen proof | "Results", "Reviews", "Start here" |
| Bio + link | The conversion point | Link hub -> bonus/review page |
| DMs | 1:1 selling | Answer questions, send links |

## The growth system

1. **Optimize your profile:** clear niche, benefit-driven bio, link hub.
2. **Post Reels for reach:** 4-7/week, strong 3-second hooks.
3. **Post carousels for saves/authority:** teach one idea well.
4. **Show up in Stories daily:** the trust + selling engine.
5. **Engage:** reply to comments/DMs fast (the algorithm and humans reward it).
6. **CTA to your link hub:** route to a lead magnet or bonus page.

## The Stories selling sequence (soft + effective)

1. **Tease** a problem ("Struggling with `[X]`?").
2. **Teach** a quick tip (build trust).
3. **Demo** a result or tool.
4. **Offer** with a link sticker (-> bonus page) + urgency.
5. **Recap** with social proof / a reply screenshot.

## Bio + link strategy

- Bio: who you help + the result + a CTA ("Free `[lead magnet]` 👇").
- Use a link hub that routes to your opt-in (Product 6) or bonus page (Product 2).
- Update Highlights: "Start Here", "Reviews", "Results", "Free Stuff".

## Compliance

- Disclose affiliate links (#ad / "affiliate link").
- Don't buy fake followers/engagement.
- Follow Instagram's promotion rules.

## How to use (for the affiliate)

1. Optimize your profile + link hub.
2. Post Reels (reach) + carousels (authority) consistently.
3. Run the Stories selling sequence on promo days.
4. Move followers to your email list so you own the audience.
