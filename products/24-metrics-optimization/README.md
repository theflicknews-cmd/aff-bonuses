## The affiliate funnel (and the metric at each stage)

```
Impressions -> Clicks -> Opt-ins -> Clicks to offer -> Sales -> Revenue
     |           |          |            |              |         |
    CTR     visitors    opt-in %      CTR to offer   conv %     EPC
```

## The metrics that matter (and benchmarks)

| Metric | What it means | Lever to improve it |
|--------|---------------|--------------------|
| CTR (content/ads) | % who click | Better hooks, titles, thumbnails |
| Opt-in rate | % who join your list | Stronger lead magnet + headline |
| Click-to-offer rate | % who click your affiliate link | Better bridge/review copy, clearer CTA |
| Conversion rate | % of clicks that buy | Better offer fit + bonus stack |
| EPC (earnings/click) | avg $ per click sent | Higher-converting offer + bonuses |
| Refund rate | % refunded | Promote quality, set right expectations |
| Email open rate | % who open | Better subject lines, list hygiene |
| ROAS (paid) | revenue / ad spend | Kill losers, scale winners |

> EPC is your north star: it tells you how much each click is worth, so you know how
> much you can spend to get one.

## The optimization loop

1. **Measure** one campaign end to end.
2. **Find the weakest step** (where the biggest % drop happens).
3. **Change ONE thing** at that step (one variable at a time).
4. **Re-measure** and compare.
5. **Keep the winner**, repeat on the next weakest step.

## Common weak points + fixes

- **Low CTR:** weak hook/title -> use Products 17 & 7.
- **Low opt-in:** weak lead magnet/headline -> use Products 6 & 17.
- **Low click-to-offer:** unclear bridge/review -> use Products 2, 10, 11.
- **Low conversion:** wrong offer or weak bonus -> use Products 20 & 2.
- **High refund:** overpromising -> be honest, set expectations.
