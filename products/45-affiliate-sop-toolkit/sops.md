# Copy-Paste SOPs + Dashboards

Adapt each SOP to your tools. Store them all in one "wiki" (Notion/Drive).

---

## SOP 1 — Offer Selection
1. Identify audience's current #1 problem.
2. Find 3-5 candidate offers on the networks.
3. Score each with the scorecard (Product 20).
4. Check refund rate, funnel, commission, reputation.
5. Pick the highest scorer you'd genuinely recommend.
6. Get approval + link; save assets + dates.
**Standard:** only promote offers scoring 24+/40 that you'd stand behind.

## SOP 2 — Promo Launch
1. Set dates + build bonus stack (Products 25, 2).
2. Write/schedule email sequence (Product 4) + content (Products 3, 7).
3. Pre-warm audience (no pitch).
4. Open day: email + post everywhere + pin link.
5. Mid-promo: value, proof, objections.
6. Close: urgency + last call + bonus deadline.
7. Post: downsell, deliver bonuses, debrief (Product 29).
**Standard:** every promo has a bonus page, a deadline, and a debrief.

## SOP 3 — Content Production
1. Pull a topic from the idea list.
2. Create the pillar piece (draft with Product 1).
3. Repurpose into formats (Product 8).
4. Add CTAs to opt-in/bonus page.
5. Schedule across the week (Product 3).
**Standard:** value 4 : promo 1; every promo piece links to a page, not a raw link.

## SOP 4 — Email
1. Choose segment (engaged/relevant).
2. Write/adapt from swipes (Products 4, 37).
3. Run the deliverability per-send checklist (Product 42).
4. Send at the best time; 1-2 links max.
5. Log opens/clicks/sales.
**Standard:** value emails between promos; never email the dead list.

## SOP 5 — List Growth
1. Maintain one strong lead magnet + opt-in (Products 6, 36).
2. Drive chosen traffic sources to it weekly.
3. Welcome new subs immediately.
4. Tag by source/interest.
**Standard:** every piece of content has a path to the opt-in.

## SOP 6 — Tracking & Review
1. Log each campaign's funnel numbers (Product 24).
2. Identify the weakest step.
3. Change ONE variable; re-measure.
4. Keep winners; document the learning.
**Standard:** decisions are made on data, weekly + monthly.

## SOP 7 — Bonus Delivery
1. Buyer purchases through your link.
2. Verify (receipt/affiliate ID).
3. Deliver bonus links automatically or within X hours.
4. Tag as buyer for future offers.
**Standard:** bonuses delivered fast = fewer refunds.

## Daily Dashboard
- [ ] Post / publish today's content
- [ ] Engage: reply to comments + DMs (Product 27)
- [ ] Check stats: clicks, opt-ins, sales
- [ ] One outreach or relationship action

## Weekly Dashboard
- [ ] Batch + schedule next week's content
- [ ] Send 1-2 value emails (+ any promo)
- [ ] Run ONE growth experiment
- [ ] Review weekly numbers; note 1 improvement
- [ ] Document/refine one SOP

## Monthly Dashboard
- [ ] Full metrics review (Product 24): clicks, conv %, EPC, MRR
- [ ] What to scale / what to cut
- [ ] Plan next month's promos (Product 44 calendar)
- [ ] Update the idea list + swipe folder
- [ ] Set next month's #1 focus

---

*Write it once, follow it always, refine it monthly. Systems turn effort into a
business that runs - and can grow beyond you.*
