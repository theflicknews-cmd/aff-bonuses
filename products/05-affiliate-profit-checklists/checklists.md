# The Affiliate Profit Checklist Pack

5 checklists covering the full promo lifecycle. Print or check off digitally.

---

## Checklist 1 — Pre-Promo Setup

- [ ] Choose an offer that matches your audience's #1 problem
- [ ] Confirm the commission %, refund rate, and EPC (earnings per click)
- [ ] Read the offer's promo/spam rules and prize terms
- [ ] Request your affiliate link / get approved by the vendor
- [ ] Grab a sample (request a review copy if available)
- [ ] Set up link tracking (cloaked link + UTM tags)
- [ ] Note the cart open & close dates and price changes
- [ ] Check the vendor's swipe file & assets (but rewrite, don't copy)
- [ ] Decide your angle (what makes *your* promotion different)

## Checklist 2 — Bonus Creation & Stack

- [ ] List the problems buyers face *right after* purchase
- [ ] Create or select 3–5 bonuses that solve those next problems
- [ ] Give each bonus a benefit-driven title and a dollar value
- [ ] Make sure total bonus value far exceeds the product price
- [ ] Build the bonus delivery method (download page / autoresponder tag)
- [ ] Create the bonus page (headline, stack, urgency, how-to-claim)
- [ ] Add an honest affiliate disclosure
- [ ] Test the buy → deliver flow end to end
- [ ] Add a deadline to drive urgency

## Checklist 3 — Launch-Day Execution

- [ ] Confirm cart is live and your link tracks correctly
- [ ] Send the "it's live" email at peak open time
- [ ] Post the launch announcement on all social channels
- [ ] Pin/feature the bonus page link (bio, story, pinned post)
- [ ] Reply to comments & DMs quickly (questions = warm buyers)
- [ ] Monitor your affiliate dashboard for clicks vs sales
- [ ] Send a midday follow-up if open rate was low
- [ ] Screenshot early results for social proof
- [ ] Watch for and fix any broken links

## Checklist 4 — Traffic & Promotion

**Free traffic**
- [ ] Email your list (use the swipe sequence)
- [ ] Post value content leading to the offer (see content calendar)
- [ ] Answer relevant questions in communities/forums (where allowed)
- [ ] Publish a review/comparison post or video
- [ ] Repurpose one piece of content into 4+ formats

**Paid traffic (optional)**
- [ ] Set a daily budget and break-even target
- [ ] Run one ad angle at a time, then scale winners
- [ ] Retarget bonus-page visitors who didn't buy
- [ ] Track ROAS daily; kill losers fast

## Checklist 5 — Post-Promo Optimization

- [ ] Record total clicks, sales, conversion rate, and EPC
- [ ] Note which email/subject line and which post drove the most sales
- [ ] Thank buyers and deliver bonuses promptly (reduces refunds)
- [ ] Send a "you missed it" / downsell email
- [ ] Ask buyers for a testimonial
- [ ] Save the best-performing assets to a swipe folder for reuse
- [ ] Add buyers to a segment for future relevant offers
- [ ] Write down 1 thing to improve next promo
- [ ] Decide the next offer to promote to this audience

---

*Tip: keep these as living docs — every promo makes the next one sharper.*
