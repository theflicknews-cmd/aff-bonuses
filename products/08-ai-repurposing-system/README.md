## The "1-to-10" content tree

Start with **one pillar asset** (a blog post, video, or long caption). Branch it:

```
            PILLAR PIECE (1)
            /     |      \
     EMAIL   SHORT-VIDEO   CAROUSEL
       |         |            |
   SUBJECT    3x CLIPS     QUOTE IMG
    LINES        |            |
              CAPTIONS    X THREAD
                 |
             LINKEDIN POST
```

From one pillar you realistically get: 1 email, 1 X/Twitter thread, 1 LinkedIn
post, 1 carousel, 3 short-video scripts, 5 standalone captions, and a handful of
quote graphics. That's **10+ posts from one idea.**

## The weekly workflow (2 hours -> a week of content)

| Step | Time | Action |
|------|------|--------|
| 1 | 20 min | Create or pick ONE pillar piece |
| 2 | 15 min | Run the "extract key points" prompt |
| 3 | 30 min | Generate platform versions (prompts 2-6) |
| 4 | 20 min | Edit for your voice + add CTAs |
| 5 | 15 min | Schedule across the week |
| 6 | 20 min | Generate next week's hooks while you're in flow |

## Repurposing rules that keep it converting

1. **One idea per piece** — don't cram; clarity wins reach.
2. **Native formatting** — a tweet isn't a caption isn't an email. Reformat, don't paste.
3. **Spread the CTA** — most pieces give value; ~1 in 5 points to your offer.
4. **Recycle winners** — top performers can be re-posted in 30-60 days, reworded.
5. **Batch + schedule** — consistency beats intensity for affiliate trust.
