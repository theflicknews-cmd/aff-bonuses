## 1. Lead-Magnet (Opt-in) Funnel — *goal: capture emails*
**Pages:** Opt-in → Thank-You/Bridge → (email sequence)
- **Opt-in page:** benefit headline, subhead, 3 bullets, email form, 1 testimonial,
  privacy line. ▶ "Build an opt-in page for `[lead magnet]`: headline about `[result]`,
  3 bullets, email form, one testimonial, privacy line."
- **Thank-You/Bridge page:** confirmation, deliver the magnet, soft pitch to `[offer]`.
  ▶ "Create a thank-you page that delivers `[magnet]` and pre-sells `[offer]` with a CTA."

## Build-in-order rules (for every blueprint)

1. Generate the **money page first** (sales/offer/opt-in) so everything points to it.
2. Build supporting pages in flow order, linking each CTA to the next step.
3. Add **one clear CTA per page** matching the funnel goal.
4. Run a **mobile pass** and a **conversion review** on each page (see Bonus 1, Combo D).
5. Add tracking + disclosures before going live.
